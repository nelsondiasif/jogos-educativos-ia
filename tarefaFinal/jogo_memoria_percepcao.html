📌 Orientações para os acadêmicos

Este jogo foi feito em um único arquivo HTML. Ele trabalha coordenação motora no toque/clique, memória visual, atenção, percepção e associação de imagens.

Onde alterar as cartas do jogo?

  • Procure no código JavaScript a lista chamada itensDoJogo.
  • Para trocar as imagens, altere o campo emoji.
  • Para trocar o nome que aparece na carta, altere o campo nome.
  • Para aumentar ou diminuir a quantidade de pares, adicione ou remova linhas dentro da lista.

Exemplo: para trocar maçã por cachorro, substitua { emoji: "🍎", nome: "Maçã" } por { emoji: "🐶", nome: "Cachorro" }.

Sugestões de adaptação: animais, frutas, formas geométricas, cores, instrumentos musicais, números ou elementos da cultura local.
