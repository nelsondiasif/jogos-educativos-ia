Para o professor: este jogo trabalha coordenação motora fina, percepção visual e correspondência número-quantidade. A criança deve tocar no número, arrastar até o conjunto com a mesma quantidade e soltar. Para mudar o tema, edite os emojis no bloco items dentro do JavaScript.

📌 Orientações para os acadêmicos alterarem o jogo

Para modificar os números e as quantidades do jogo, procure no código a parte marcada com o comentário EDITE AQUI. Ela fica dentro do JavaScript, perto do final do arquivo HTML.

O trecho principal é este:

const items = [
  { number: 1, emoji: '🍎' },
  { number: 2, emoji: '🐝' },
  { number: 3, emoji: '⭐' },
  { number: 4, emoji: '🌸' },
  { number: 5, emoji: '🎈' }
];
  • Para alterar o número: mude o valor depois de number:. Exemplo: { number: 6, emoji: '🐠' }.
  • Para alterar a quantidade: o próprio número define quantas figuras aparecem. Se colocar number: 6, aparecerão 6 emojis.
  • Para alterar a imagem: troque o emoji depois de emoji:. Exemplo: emoji: '🚗'.
  • Para aumentar o jogo: acrescente novas linhas dentro do bloco items, separando cada uma por vírgula.
  • Para diminuir o jogo: apague uma ou mais linhas do bloco items.

Exemplo com números de 1 a 8:

const items = [
  { number: 1, emoji: '🍎' },
  { number: 2, emoji: '🐝' },
  { number: 3, emoji: '⭐' },
  { number: 4, emoji: '🌸' },
  { number: 5, emoji: '🎈' },
  { number: 6, emoji: '🐠' },
  { number: 7, emoji: '🚗' },
  { number: 8, emoji: '🦋' }
];

Depois de alterar, salve o arquivo e abra novamente no navegador para testar. A criança deve ligar cada número ao grupo que apresenta a mesma quantidade de figuras.
